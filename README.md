# MediCare Plus - Dynamic PHP Healthcare Web Application

MediCare Plus is a role-based healthcare web application built using **PHP, HTML, CSS, JavaScript, and SQLite**.

## Features
- Detailed doctor profiles with specialization, availability, fees, and ratings
- Categorized healthcare service listings
- Appointment booking and status management
- Patient registration/login with secure authentication
- Medical report publishing and access
- Secure messaging between users
- Search/filter functionality
- Feedback and ratings
- Role-based authorization for Admin, Doctor, and Patient
- Futuristic animated UI theme
